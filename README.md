# 짐노트

- 루틴을 폴더처럼 만들고 선택
- 루틴 관리 탭에서 루틴별 운동 종목 구성
- 어깨, 가슴, 등, 복근, 하체 카테고리에서 루틴에 넣을 운동 선택
- 루틴 편집 화면에서 새 운동 종목 추가
- 기존 루틴 삭제
- 기록 탭에는 오늘 선택한 루틴에 추가된 운동만 표시
- 운동을 누르면 상세 기록 화면으로 이동
- 웜업, 탑 세트, 본 세트별 중량과 횟수 기록
- 세트 체크 시 설정한 쉬는시간 타이머 표시
- 운동 종료 시 해당 루틴의 운동 세션 저장
- 운동별 최고 무게와 개수 저장
- 달력에서 날짜별 운동 기록 확인
- 종목별 최고 중량 추이 그래프 확인
